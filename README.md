# EarthNeer

**Pure Water. Better Earth.**

EarthNeer is a proposed packaged drinking-water venture based in Chandwa, Jharkhand, India.

## Project

This repository contains a working prototype built with:

- React
- Vite
- JavaScript
- CSS
- Python
- Flask
- JSON storage

## Architecture

React + Vite → Flask REST API → data.json

## Features

- Product display
- EarthNeer proposed facility information
- Target market
- Sustainability vision
- Future growth roadmap
- Enquiry form
- Flask REST API
- JSON-based enquiry storage
- Dashboard statistics

## Important Note

EarthNeer is a proposed venture and prototype.

The plant, investment, production operations, customers, certifications, approvals and partnerships described in the project are proposed/planned concepts and should not be interpreted as existing achievements.
